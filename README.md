# Student Management System

## Description
A simple Student Management System developed using HTML and CSS. The project provides basic navigation between pages for managing student information.

## Features
- Home Page
- User Registration Page
- User Login Page
- Dashboard
- Add Student Page
- View Students Page
- Edit Student Page
- Logout Page
- Responsive Design using CSS

## Technologies Used
- HTML5
- CSS3
